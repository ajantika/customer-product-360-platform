# Customer & Product 360 Platform

Self-service intelligence across **product usage, customer segmentation, and monetization** — designed for sales, product, and customer-success teams to answer their own questions about pricing, adoption, and churn risk without waiting on the analytics team.

A portfolio recreation of a platform built at a previous company. Synthetic data, real architecture.

## Live demo

> Deploy on Streamlit Community Cloud — see [Deploy](#deploy) below.

## What's inside

| Page | What it shows |
|---|---|
| **Home** | KPI tiles (MRR, active customers, % over/under-utilized), MRR by region, top products by adoption, customer utilization distribution |
| **Customer List** | Searchable, filterable customer table — click a row to drill in |
| **Customer 360** | Per-customer view: products with utilization badges, regional footprint, MoM usage trend, **Ask AI** panel |
| **Product List** | All products with adoption %, attributed MRR, top customers per product |
| **Product 360** | Per-product view: regional adoption, MoM trend, top customers, **Ask AI** panel |
| **Cohorts** | Auto-generated segments: upsell candidates, churn risk, MRR-at-risk |

## Architecture

```
User → Streamlit (multi-page) → pandas / plotly  → parquet files in data/
                              → Groq + Llama 3.1 (Ask-AI panels)
```

- **Data layer:** four parquet files generated by `scripts/generate_data.py` (seed=42, reproducible).
- **Compute:** all metrics in `lib/metrics.py` — pure pandas, cached via `@st.cache_data`.
- **LLM:** single helper `lib/llm.ask_about(context, question)` shared by both Customer 360 and Product 360.
- **UI:** dark-theme CSS in `lib/theme.py` applied at the top of every page.

## Run locally

```bash
git clone <this repo>
cd customer-product-360-platform
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# 1. Generate the synthetic data
python scripts/generate_data.py

# 2. Configure your Groq key (optional — the dashboards work without it,
#    only the Ask-AI panels need it)
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# edit secrets.toml and paste your GROQ_API_KEY

# 3. Run
streamlit run app.py
```

## Deploy to Streamlit Cloud

1. Push this repo to GitHub.
2. On [share.streamlit.io](https://share.streamlit.io), create a new app pointing at `app.py`.
3. In the app's **Settings → Secrets**, add:
   ```
   GROQ_API_KEY = "your-key-here"
   ```
4. The data parquet files are committed to the repo — no build-time generation needed.

## Data

100% **synthetic** — generated from a fixed seed so results are reproducible. Schema: see [`data/README.md`](data/README.md).

- 200 customers across NAMER / EMEA / APAC / LATAM
- 8 products (API Gateway, Object Storage, CDN, Compute, Analytics, Identity, Workflow, Edge Functions)
- ~600 active subscriptions
- 24 months of monthly usage data ending May 2026

The generator (`scripts/generate_data.py`) deliberately produces realistic distributions:
- ~25% of subscriptions over-utilized (>100% of plan limit)
- ~40% under-utilized (<50%)
- ~35% healthy
- "at_risk" customers show declining trends in the last 6 months
- "churned" customers drop to zero usage in the last 3 months

Re-run the generator any time to refresh the data.
